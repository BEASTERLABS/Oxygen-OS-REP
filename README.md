# Oxygen Clock

An OxygenOS-inspired Android home-screen widget with weekday, large digital clock (red first hour digit), date, and current weather.

- Weather city is selected manually by tapping the widget/configuring it.
- Weather data is provided by Open-Meteo; no API key or location permission is required.
- GitHub Actions builds a debug APK on each push to main.

## Get the APK
Open the repository's Actions tab, choose the latest successful **Build Oxygen Clock APK** run, and download the **OxygenClock-debug-apk** artifact.
